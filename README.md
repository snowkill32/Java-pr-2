`Результат.txt` в папках соответствующих частей.

## Запуск

Нужен JDK 8 или новее. Каждая часть запускается отдельно.
В IntelliJ IDEA откройте папку нужной части, отметьте `src` как Sources Root
и запустите `Main` или `TestCar`.

Для запуска в терминале из корня репозитория:

### Часть 1

```powershell
cd Практика_2/Часть_1
javac -encoding UTF-8 -d out src/vehicles/Car.java src/vehicles/ElectricCar.java src/app/Main.java
java -Dfile.encoding=UTF-8 -cp out app.Main
```

### Часть 2

Откройте новый терминал в корне репозитория:

```powershell
cd Практика_2/Часть_2
javac -encoding UTF-8 -d out src/vehicles/Vehicle.java src/vehicles/Car.java src/vehicles/ElectricCar.java src/app/TestCar.java
java -Dfile.encoding=UTF-8 -cp out app.TestCar
```
